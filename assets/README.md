# Artwork

`logo.svg` and `architecture.svg` are original vector illustrations created for this project. They use text and geometric shapes, include accessible titles and descriptions, and require no external fonts or images. They are covered by the repository license. Software names identify integrations; the illustrations are not vendor logos or endorsements.
